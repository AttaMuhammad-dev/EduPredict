DISTRIBUTED BIG DATA ANALYTICS PLATFORM

Distributed Intelligence for Student Success

EduPredict predicts student dropout risk using a lightweight Python alternative to the Hadoop Big Data stack. It combines HDFS-style partitioned storage, parallel MapReduce processing, and automated email alerts inside a single Flask application.

THE PROBLEM WE SOLVE

From Scattered Records to Early Warnings

DESIGN GOAL

Institutes already store attendance, marks, and LMS data. The problem is not the lack of data — it is the lack of a system that can read, clean, and act on it before it is too late for the student.

Using Python's pandas and multiprocessing, we replicate how Hadoop works — split the data, process it in parallel, and reduce it into clear risk scores. No JVM, no YARN, no cluster. Just Flask, a database, and clean Python.

How the Pipeline Works

  • 01
    Chunked Data Ingestion Records split into chunks; missing values filled with mean or mode imputation.
  • 02
    Parallel MapReduce Scoring Multiprocessing scores students across CPU cores, then reduces per cohort.
  • 03
    Scikit-Learn Models Random Forest, Logistic Regression, and Ridge models run per student.
  • 04
    Automated Email Alerts SMTP gateway emails the teacher or advisor when risk crosses a threshold.
